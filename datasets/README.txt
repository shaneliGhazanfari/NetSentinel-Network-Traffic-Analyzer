UNSW-NB15 Dataset
=================

This project uses the UNSW-NB15 dataset for network traffic analysis and cybersecurity research.

The dataset files are not included in this repository because of their large file size.

Official dataset source:
https://research.unsw.edu.au/projects/unsw-nb15-dataset

Please download the required dataset files from the official UNSW source
and place them in this folder before running the analysis.

Expected dataset files:
- UNSW-NB15_1.csv
- UNSW-NB15_2.csv
- UNSW-NB15_3.csv
- UNSW-NB15_4.csv
- UNSW-NB15_features.csv
- UNSW-NB15_LIST_EVENTS.csv
